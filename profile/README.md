Which parts are in my car, what fits it, and what is it equivalent to?
An open, cross-brand parts database for hobbies, starting with RC cars.
Facts with their source, no prices, no images. Data is CC0.

- [hobbydex-rc](https://github.com/hobbydex/hobbydex-rc): the RC dataset, one TOML file per entity, validated in CI
- [hobbydex](https://github.com/hobbydex/hobbydex): the website, built from the dataset exports, at [hobbydex.com](https://hobbydex.com)
