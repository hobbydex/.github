# Logo

- `hobbydex-mark.svg`: the mark on its rounded blue tile, for favicons and anywhere the tile is shown as is; `hobbydex-mark-512.png` is the same as a bitmap
- `hobbydex-avatar.svg` and `hobbydex-avatar-512.png`: the mark on a square, full-bleed blue background, for avatars where the host applies its own rounding (GitHub, social profiles); using the rounded tile there gives a double border
- `hobbydex-mark-blue.svg`: the mark alone, blue on transparent, for light backgrounds
- `hobbydex.svg`: wordmark for light backgrounds, text outlined
- `hobbydex-dark.svg`: wordmark for dark backgrounds, text outlined
- `hobbydex-text.svg`: the wordmark with live text, the editable source of the two above

The mark is an H with four fading, rotating copies behind it. Colours are
GitHub Primer's accent blue (#0969da light, #58a6ff dark) and text colours.
